## Reproduce uncommitted artifacts (fresh checkout)

> **DB 전환 (2026-09-19)**: Prisma는 이제 **Supabase PostgreSQL**을 사용 (provider postgresql). `.env.local`의 `DATABASE_URL`은 트랜잭션 풀러(포트 6543, `?pgbouncer=true`), `DIRECT_URL`은 세션 풀러(포트 5432) — db push/prisma CLI는 directUrl 사용. 스키마는 `npm run build`에 포함된 `prisma db push --skip-generate`가 자동 적용하므로 별도 db push 불필요 (아래 3번 레거시 단계는 SQLite 시절 절차 — 이제 무시). 기존 SQLite 데이터는 이전하지 않기로 함(사용자 선택), 백업은 /tmp/dev.db.backup-*.

1. Copy env file from the main checkout:
   - `cp /Users/littlemac/Documents/Codex/2026-09-14/files-pasted-by-the-user-pdf/.env.local .env.local`    - It contains `DATABASE_URL` (SQLite file URL), `GEMINI_API_KEY`, and an optional commented-out `GEMINI_MODEL`. Never commit or print the values.
2. Install dependencies with npm (project uses a `package-lock.json`):
   - `npm install`
3. Create/sync the SQLite database (0-byte `prisma/dev.db` breaks every API route):
   - `set -a; source .env.local; set +a; npx prisma db push --skip-generate`

4. `next.config.ts` marks `pdfjs-dist` as a `serverExternalPackages` entry. It is required — without it pdf.js's worker dynamic import fails under Turbopack and PDF upload always 500s. Keep it.
5. Optional test asset: `work/pdf-test/text-based-source.pdf` (2-page text PDF used to exercise `/api/documents/upload`).

## Run the server

- Command: `npm run dev` (Next.js 16 dev server, default port **3000**; if 3000 is busy Next picks a random port — check the `Local:` line in the log).
- Interactive/detached-in-shell launch (macOS) — works only when the shell's process group survives:
  `{ nohup npm run dev > "<log>" 2>&1 < /dev/null & echo "pid=$!"; disown; }`
- **Proven background recipe for this workspace (launchd)** — plain `nohup` gets reaped by the command runner, and under `launchctl submit` both the `npm` wrapper and a redirect into `.freebuff/*.log` produced instant exit-1/empty-log respawns. The combination that survives is direct `node` + `/tmp` log:
  ```
  launchctl submit -l probe-tmp-log -- /bin/sh -c 'echo probe-start; cd /Users/littlemac/Documents/Codex/2026-09-14/files-pasted-by-the-user-pdf && exec /opt/homebrew/bin/node node_modules/next/dist/bin/next dev -p 3000 > /tmp/dev-launchd.log 2>&1'
  ```
  - Take the pid from `launchctl print gui/$(id -u)/probe-tmp-log` (grep `pid =`).
  - Stop when done: `launchctl remove probe-tmp-log` (this kills the server too).
- Health check: `curl -s -o /dev/null -w '%{http_code}' http://localhost:3000` → expect `200`.
